# Overview
This is a website that tells people who I am, my thoughts on books, and serves as a portfolio for all my future projects.
### Me
The "Me" page introduces me, tells you my name, and my goals and aspirations. It also includes a link to my Linktree, if you wish to contact me or see my work. It also features an About Me section, which you can read to learn more about me as a person. Lastly, it includes a Contact section, where you can access a link that will open a page where you can email me.
### Books
This page is the main bulk of the website. Here, you can view a collection of all the books I have read, along with my thoughts on them. You can use it by clicking on each book/series card, and for series', you can click on the book cards within the series popup to view information about each book in the series.
